# 循環特攻隊：搶救資源星球！

適用於國小三、四年級的資源回收互動學習網站。

## 三站宜蘭任務

1. 頭城：紙類回收大冒險
2. 五結：紙餐具清分疊大作戰
3. 蘇澳：高壓容器完包警收大作戰

網站包含中文配音、臺灣繁體中文字幕、互動闖關、即時回饋、學習進度與單張 A4 證書。學生必須完成每一個關卡並達到過關條件，才能取得證書。

## 操作方式

使用瀏覽器開啟 `index.html`，或進入 GitHub Pages 公開網址。網站支援電腦、平板與手機操作，學習進度儲存在使用者目前的瀏覽器中。

## 教學安全提醒

高壓容器任務以辨識與安全觀念為主，不安排學生操作、刺穿、排空、敲擊或壓扁真實容器。實際回收方式仍應依所在地清運及回收單位規定辦理。
